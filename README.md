# Python Expense Tracker

A beginner-friendly Expense Tracker built using Python.

## Features
- Add Income
- Add Expense
- View Transactions
- Calculate Balance
- Input Validation
- Save and Load Data using JSON

## Technologies Used
- Python
- JSON

## How to Run

1. Install Python.
2. Clone this repository.
3. Open the project folder.
4. Run:

```bash
python expense_tracker.py
```
